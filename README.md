
# ⚡ Selección de descargadores para transformadores rurales 40/50 kVA

## 📌 Descripción
Herramienta desarrollada para seleccionar descargadores de sobretensión específicamente para transformadores rurales de:

- 40 kVA
- 50 kVA

## 🎯 Objetivo
Brindar una guía rápida y práctica para la correcta selección de descargadores en este tipo de transformadores, mejorando la protección frente a sobretensiones atmosféricas y transitorias.

## 🧠 Alcance
Esta aplicación está limitada a:
- Transformadores rurales de 40 kVA y 50 kVA
- Condiciones típicas de redes de distribución rural

No contempla otros niveles de potencia ni configuraciones especiales.

## 🧠 Criterios técnicos
- Selección basada en prácticas comunes de distribución eléctrica
- Consideración de tensión del sistema
- Criterios básicos de coordinación de aislamiento

## 🚀 Uso
1. Abrir el archivo `index.html`
2. Ingresar los datos solicitados
3. Obtener recomendación del descargador aplicable

## 🛠 Tecnologías
- HTML
- CSS
- JavaScript
